# Silmärin

Silmärin is a library for documentation of my projects, built with [Zensical](https://zensical.org/) and published at [lumikeiju.dev/silmarin](https://lumikeiju.dev/silmarin/).

`main` contains source and runs CI without deploying. The manual **Promote site** workflow builds a beta candidate, then publishes that tested artifact to `stable` without rebuilding. GitHub Pages serves the `stable` branch root. See the [release process](CONTRIBUTING.md#releases).

## Contributing

Silmärin does not accept external contributions.

# Pride Map

Ultra-powered visualization of LGBTQ+-friendliness data in OpenStreetMap.

- **Website**: [lumikeiju.dev/pride-map](https://lumikeiju.dev/pride-map/)
- **Repository**: [github.com/lumikeiju/pride-map](https://github.com/lumikeiju/pride-map)

## Contents

- OpenStreetMap data using the `lgbtq` and `lgbtq:signed` tags
- Ultra map styles, icons, and supporting utilities
- An Every Door tagging plugin (in development)

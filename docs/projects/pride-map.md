# Pride Map

An interactive web map visualizing LGBTQ+-friendliness data in OpenStreetMap.

- **Website**: [lumikeiju.dev/pride-map](https://lumikeiju.dev/pride-map)
- **Repository**: [github.com/lumikeiju/pride-map](https://github.com/lumikeiju/pride-map)

## Overview

Pride Map renders LGBTQ+-friendliness data collected using [Microcosm](https://github.com/watmildon/microcosm) from OpenStreetMap via an [Ultra](https://overpass-ultra.us/)-based web map.

# ImproveNode

A JOSM plugin for refining the position of isolated nodes in OpenStreetMap.

- **Repository**: [github.com/lumikeiju/improve-node](https://github.com/lumikeiju/improve-node)

## Overview

ImproveNode adapts the _ImproveWay_ plugin for nodes that have no parent way. It extends JOSM's familiar _ImproveWayAccuracy_ workflow to standalone points, keeping precise corrections quick and consistent.

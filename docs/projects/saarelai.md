# Saarelai

JOSM plugins, tagging presets, MapCSS paint styles, and validator rules, maintained and versioned independently.

- **Repository**: [github.com/lumikeiju/saarelai](https://github.com/lumikeiju/saarelai)

## Plugins

- **[Arkki Snappi](https://github.com/lumikeiju/saarelai/tree/main/plugins/arkki-snappi)**: Building footprint mapping with a 2-axis snap grid and edge extrusion.
- **[Improve Node](https://github.com/lumikeiju/saarelai/tree/main/plugins/improve-node)**: Correcting standalone node positions against imagery.
- **[Easy Pan](https://github.com/lumikeiju/saarelai/tree/main/plugins/easy-pan)**: Panning with a held activation key and pointer movement.

## Organization

Each component owns its source, tests, metadata, and changelog. Shared release automation publishes beta artifacts and promotes tested builds to stable.

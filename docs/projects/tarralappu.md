# Tarralappu

Sticky-note-themed browser interface for AI image generation through OpenRouter.

- **Website**: [lumikeiju.dev/tarralappu](https://lumikeiju.dev/tarralappu/)
- **Repository**: [github.com/lumikeiju/tarralappu](https://github.com/lumikeiju/tarralappu)

## Features

- Bring your own API key and choose from image-capable models.
- Combine prompt boards, style guides, and reference images.
- Refine images in chains and fork alternative versions.
- Track estimated and actual costs with configurable spending caps.

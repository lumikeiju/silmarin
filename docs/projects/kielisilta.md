# Kielisilta

Web utility for translating existing geospatial data into OSM-ready formats with custom field mapping and reprojection.

- **Website**: [lumikeiju.dev/kielisilta](https://lumikeiju.dev/kielisilta) (coming soon)
- **Repository**: [github.com/lumikeiju/kielisilta](https://github.com/lumikeiju/kielisilta)

## Overview

Kielisilta is a web utility for turning existing geospatial datasets into OpenStreetMap-ready formats through custom field mapping and reprojection.
